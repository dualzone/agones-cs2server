# Présentation générale

Cette plateforme vise à offrir un environnement de jeu compétitif sécurisé et performant pour des matchs 1v1 et 2v2 de Counter-Strike. Inspirée par des plateformes reconnues comme Faceit et ESEA, elle met l'accent sur la sécurité, la modération et la performance. Elle répond à la demande croissante de joueurs cherchant des environnements bien régulés et sécurisés.

# Description

Ce dépôt contient le code pour la gestion du cycle de vie des serveurs de jeux. Il est développé en Python et utilise Redis pour la gestion des événements et des communications. L'objectif est de gérer efficacement le démarrage, l'arrêt et le monitoring des serveurs de jeux.

# Technologies utilisées


- Python : Pour l'implémentation des services de gestion des serveurs.
- Redis : Pour le cache serveur et la gestion des événements.
- MatchZy : Gestion du cylle de jeux dans CS2


# Fonctionnalités principales

- Gestion du cycle de vie des serveurs : Démarrage, arrêt et monitoring des serveurs de jeux.
- Communication : Utilisation de Redis pour la gestion des événements et des communications avec le backend
